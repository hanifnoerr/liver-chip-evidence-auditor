# Framework verification map

Verified against the implemented functions on 5 October 2026. The three figures separate numerical inference, optional action-code inference, and documented evidence reassessment.

| Figure operation | Input and output | Supporting implementation |
| --- | --- | --- |

The numerical objective is sum_j n_j (z_j-m_j)^2 under z_j >= z_(j+1). PAVA pools adjacent increasing blocks using observed counts. Conventional fitted response values are not pretrained neural parameters. The model scores S(c)=mean_t log p_theta(c_t | prompt,c_<t); adaptation includes EOS in the supervised loss, whereas runtime code scoring excludes EOS. Solid arrows carry records, summaries or actions; the dashed checkpoint arrow assigns the selected adapted parameters to inference. Source cards bypass the model.

Real example: Clozapine's ALBUMIN!C12 contains 69.67854% at 300 times unbound Cmax. The full primary fit is right-censored. Temporary deletion gives a crossing near 256.22 times unbound Cmax; the reading remains in the reported baseline. The adapted record-review request delivers INSPECT, and the renderer copies this card. Recording an inspection does not resolve its computed influence.

The reassessment checks require recovered originals under their existing IDs, a new observed record at the named dose for REPEAT, an added observed dose for EXTEND, or usable repaired input after a blocked baseline for FIX. INSPECT can record a documented revision; metadata-only revision does not establish a measurement change. Removed baseline IDs and observed-to-missing substitutions are rejected. Reported compatibility/reference authenticity and biological independence are not independently verified.

Editable SVGs, vector PDFs and PNG previews are generated by `build_framework.py`. Review the figures at 174 mm width, the same width used by the report. The main figure does not depict pilot bootstrap ranges as calibrated intervals. No figure depicts a measured edge device, clinical safety model, generated chip ID or automated experiment.
